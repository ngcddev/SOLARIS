# Solaris

Plataforma de coordinación y priorización de pedidos de ayuda (SOS) para las **primeras 72 horas después de un desastre**. Proyecto de la *Meta Global AI Developer Hackathon* (track Indie Developer, "Build for Your World").

> Solaris **no** da consejos médicos ni diagnostica. Es una herramienta de coordinación de recursos para rescatistas, con validación humana en cada decisión.

Este README se completa al final del desarrollo (ver `docs/ASSUMPTIONS.md` y `docs/THREAT_MODEL.md`).

## Construido durante la hackathon
Todo el código de este repositorio fue escrito entre el 27 de octubre y el 4 de noviembre de 2026.

## Concepto previo
La idea proviene de una propuesta presentada en un rally de innovación. No se reutiliza código.

## Cómo correrlo (sin credenciales)
```bash
npm install
npm run dev        # http://localhost:3000
npm run test
npm run keys
npm run scenario
```
